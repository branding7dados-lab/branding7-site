# Site da Branding7 — branding7.com.br

Next.js (App Router) com exportação estática, publicado no GitHub Pages pelo workflow `.github/workflows/pages.yml`.

- **Conteúdo** (textos, WhatsApp, vídeos, depoimentos, serviços, clientes, regiões, números, Pixel da Meta e GA4) vem do **Sistema B7**, tela **Site**. Não precisa mexer no código para atualizar o site.
- **Formulário** grava em **Site → Contatos** no sistema e avisa a administração; depois abre o WhatsApp do comercial com a mensagem pronta.
- **Rodar no computador:** `npm install` e `npm run dev`.
- **Domínio:** `public/CNAME`.
