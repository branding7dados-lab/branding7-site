# Site da Branding7 — branding7.com.br

Página institucional (marketing digital e vídeo). HTML, CSS e JS puros, sem build.

- O conteúdo (textos, WhatsApp, vídeos, depoimentos, serviços, clientes, regiões, números, Pixel da Meta e GA4) vem do **Sistema B7**, na tela **Site** — não precisa mexer aqui para atualizar o site.
- O formulário grava em **Site → Contatos** no sistema e avisa a administração.
- Publicação: GitHub Pages, branch `main`, pasta raiz. Domínio no arquivo `CNAME`.
